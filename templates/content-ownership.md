## Review workflow

1. Draft with runnable examples and an explicit intended audience.
2. Run automated checks for syntax, links, and example behavior.
3. Have the technical owner verify product behavior and constraints.
4. Have the editor check task flow, terminology, and recovery instructions.
5. Review a rendered preview on desktop and mobile.
6. Merge only after required checks pass and approvals are recorded.
